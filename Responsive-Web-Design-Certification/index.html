Certification projects

01 Hiking Experience Survey Build an accessible survey form using semantic HTML, labeled inputs, native validation, a dropdown, radio buttons, checkboxes, and a comments field. 02 The Card Table Build a webpage displaying a collection of playing cards. Use Flexbox to arrange the cards, align their elements, and create a responsive layout with suit selection. 03 Book Inventory Build a book inventory with a semantic table, reading statuses, and ratings. Use CSS attribute selectors and gradients to distinguish reading progress and personal ratings. 04 JavaScript Documentation Create a JavaScript reference with semantic topic sections, linked navigation, code examples, and a responsive sidebar that stays visible on desktop. 05 Product Landing Page Build a responsive product page with fixed navigation, an embedded video, and an email signup form.
